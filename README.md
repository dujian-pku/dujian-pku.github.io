# Jian Du / 杜建 — Academic Homepage

北京大学健康医疗大数据国家研究院杜建老师的中英文个人学术主页。英文为默认语言，中文页面位于 `/zh/`。

- 发布地址：[https://dujian-pku.github.io](https://dujian-pku.github.io)
- 内容来源：北京大学官方个人主页、ORCID 及论文出版页
- 页面框架：[academic-homepage](https://github.com/luost26/academic-homepage)（MIT License）

本地预览：

```bash
bundle install
bundle exec jekyll serve
```
